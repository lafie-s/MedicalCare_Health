# MedicalCareWeb 网站版本更新与回退

## 已实现流程

服务条目“网站版本”打开批准版本目录、当前版本和最近 20 条任务。管理员选择版本、填写变更原因及已验证备份记录编号，经二次确认提交。任务后台执行，面板每 5 秒刷新，关闭面板不会取消。成功后显示新版本，可回退至最近成功任务的原版本。只读/运维角色可以查看，执行仅限管理员；服务端逐次检查环境、角色和 Origin。

同一服务只允许一个执行中或结果未知的任务。UUID 幂等请求不重复部署，同键不同内容拒绝；当前版本变化、健康检查未通过、未批准版本或无回退历史时拒绝。任务、开始审计同事务提交后才能执行，结束审计失败时锁定记录保留。任务写入平台 SQLite，恢复备份包含此表；进程重启将执行中标为结果待核对，不自动重试。

结果不确定时禁止新任务，部署人员确认残留执行已停止后，管理员点击核对状态：目标版本健康则确认成功，原版本健康则确认未生效；混合镜像、未知版本或不健康状态保持锁定，需部署人员恢复，不能通过反复点击绕过。当前未实现对失败发布的自动回退，也不声称支持任意数据库降级。回退后最近成功任务的原版本成为下一次可回退目标。

## 已批准版本与真实执行器

生产 `server.ts` 仅在配置 RELEASE_CONFIG_PATH 时启用 Docker 执行器；公开 preview-server 始终使用内存演示执行器，没有 Docker socket 或业务网络。

部署人员以 config/releases.example.json 为格式，创建仅受控账户可写的本地文件。serviceId 必须对应已登记的 MedicalCareWeb 网站服务；一个平台实例仅绑定一个真实网站部署。deploymentDirectory 为实际绝对路径，目录内 compose.yaml/.env 必须可信且已配置。releases 至多 20 条，须包含当前基线及批准目标，每项使用唯一版本 ID 和唯一镜像组合；镜像只接受 sha256 本地不可变 ID 或 registry@sha256 摘要，拒绝 latest/可变标签。版本目录启动时载入，增减版本需重启平台，执行中不得变更或重启。

发布列表由运维审核后在部署机配置，不允许浏览器上传镜像、输入仓库地址、Shell 或 SQL。数据库兼容声明必须为 true；备份记录编号是管理员的审核依据，本阶段不会自动检查该编号对应的备份内容。需先完成备份恢复演练及版本兼容确认后启用。示例中的镜像 ID 和 serviceId 不可用于实际部署。

实际执行采用固定 Docker 命令：拉取摘要镜像/检查本地镜像；对固定 Compose 项目 deploy 的 medicalcare 与 chat 生成 image 覆盖文件；以 --no-build --no-deps 切换，仅操作网站与聊天服务，不启动 PostgreSQL/Redis、不运行 deploy-production.sh、不执行迁移或 seed。检查容器镜像与 Docker healthcheck，最长等待健康状态 150 秒，单次拉取最长 300 秒、Compose 更新最长 180 秒；之后对固定 shengren-nginx-1 执行 nginx -t 和 reload。原发布脚本包含数据库迁移，因此未直接复用。

执行器需在有 Docker CLI/Compose 和对应受控部署文件权限的主机环境运行；当前正式 Docker 模板未挂载 Docker socket 或部署目录，不能仅设置路径就获得执行能力。不要给公开演示容器授予这些权限。正式启用还需要 HTTPS、实际员工授权、备份与回退镜像就绪、维护窗口和现场验证。Docker 超时可能留下后台操作，不能根据 HTTP 超时推断未部署。镜像摘要与容器健康状态是本次验收依据，不代替公网业务流程验收。

## API 与审计

- GET /api/v1/services/:id/releases：批准版本、部署状态、最近任务；无执行器时返回 available=false，连接异常返回 503，不能将未知当作正常。
- POST /api/v1/services/:id/release：id、to、expected、action(update/rollback)、reason、backupReference；返回 202 与任务。任务来源版本存入记录，回退目标必须由上次成功记录推出。
- POST /api/v1/services/:id/release-reconcile：executionStopped=true，管理员明确确认执行已停止后才核对状态。
- 审计新增 release 分类及 started/succeeded/failed/unknown，服务环境关联复用授权。页面不返回镜像地址、部署目录或原始执行器错误。

## 演示与验证范围

腾讯云公开演示提供 1.0.0/1.1.0/1.2.0 三个示例版本，模拟切换与健康检查，重启重置；界面明确写明不部署真实网站。真实 Docker 执行器代码已实现，但没有配置生产批准版本，也没有对现有 MedicalCareWeb 执行更新或回退。自动测试覆盖成功更新回退、重复/并发、未知结果核对、不可变目录、权限及审计；真实生产发布仍待受控接入验收。


入口：首页标题旁点击网站版本更新，选择当前授权环境的目标服务，点击管理网站版本；原服务详情入口保留。公网演示仅模拟操作。
