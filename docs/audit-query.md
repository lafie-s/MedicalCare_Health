# 环境操作审计查询（F08a）

2026-09-08：新增只读接口 `GET /api/v1/audit`，仅 admin 可读取其授权环境；viewer/operator 返回 403，未登录返回 401。当前交付后端接口，查询界面待 F08b。

参数：`environmentId` 必填；`category` 为 all/service/probe/alert/maintenance，默认 all；`from`/`to` 为 UTC 毫秒，默认最近 24 小时，采用 `[from,to)`，跨度最长 31 天；`page` 默认 1、最大 100000。未知参数、无效类型或时间区间返回 400，未授权环境返回 403。

返回 `items/total/page/pageSize/from/to/asOf`；每页 20 条，按时间、审计 ID 倒序，越界页码回到末页。总数与列表在同一 SQLite 只读事务中查询。不同分页请求间新增记录可能改变页码内容，不承诺跨请求冻结快照。

记录仅返回审计 ID、操作人 ID、操作类型、UTC 时间、关联服务 ID 和当前服务名称。不返回上游凭据、会话、请求原文、原始 request_id、维护原因或配置内容。操作人 ID 保留用于追责，访问受管理员及环境授权限制。

兼容现有审计格式：服务创建/更新、探测开始直接关联服务；探测结束经 probe_runs 关联；告警规则直接关联服务，事件触发/恢复/终止/确认/关闭经 alert_events 关联；维护登记/取消经 maintenance_windows 关联。只识别明确白名单操作，不以模糊文本匹配决定权限。不能关联资源、未知操作以及没有环境归属的登录审计不返回，避免错误归属或跨环境泄漏。

当前没有服务删除接口，资源历史保留。未来引入清理/删除前必须迁移为审计写入时保存环境、资源及名称快照；否则查询无法保留资源删除后的关联。当前服务名为查询时名称。时间索引支持范围过滤；生产规模、归档和保留周期未验收。API 不提供修改/删除审计能力，数据库管理员仍可直接改库，本阶段不宣称防篡改。

验证：55 项后端测试通过，包括所有已知操作映射、无归属记录排除、同毫秒稳定排序、20 条分页、时间边界、跨环境与角色限制、参数校验和 DELETE 路由不存在。类型检查、构建及启动 smoke 通过。本轮未修改 UI，不新增浏览器验收结论。

## F08b 管理员页面

工作台当前环境下提供操作审计区，仅 admin 可见。操作类型与最近 24 小时/7 天/31 天使用原生筛选器，翻页固定结束时间，手动刷新回第一页并更新时间范围。URL 保存 auditCategory/auditDays/auditTo/auditPage，切环境重置。加载和失败隐藏旧列表，旧请求取消；401/403 清除受保护页面。记录按北京时间显示，服务名明确为当前名称，可定位服务。仍不包含无环境登录事件或数据库防篡改能力。
