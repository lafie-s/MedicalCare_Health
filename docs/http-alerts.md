# HTTP 告警规则与事件（F06a）

每个服务最多一条连续失败规则，默认不存在；页面初始示例为失败 3 次、恢复 2 次、警告等级且停用。管理员必须主动保存并启用，示例不是生产阈值。触发及恢复次数均为 1～10，等级为 warning / critical。规则对保存之后的新采样生效，不追溯触发历史样本。

## 判定与生命周期

有效失败包括 HTTP 非 2xx、超时和连接失败，成功为 HTTP 2xx。连续失败达到触发次数后生成一个 firing 事件；同一服务仅允许一个 firing/acknowledged 事件，后续失败更新最后采样时间，不重复生成事件。连续成功达到恢复次数后转为 recovered。相邻样本间隔超过 `2 × 采集间隔 + 5 秒`、中断或过期样本打断连续计数。没有新样本不会恢复已有事件；面板同时展示采样状态和查询时间，避免把旧事件状态当作当前探测结果。

运维人员或管理员可将 firing 确认为 acknowledged，确认仅表示有人跟进。仅 recovered 可关闭为 closed；确认及关闭重复请求返回已有结果，不重复审计，不覆盖首位确认人。提前关闭、对已恢复事件重新确认返回 409。本阶段没有误报关闭入口。

规则保存/停用、服务配置修改/停用会在配置事务内终止活动事件，状态为 terminated，记录原因而非伪装成恢复。目标指纹、环境授权配置变更由采集轮次核对，正常情况下在下一轮完成终止；授权文件读取失败则暂停该轮评估并记录采集器错误，不推断恢复。恢复和终止后的历史保留，新的失败序列可以创建新事件。

## 存储与一致性

规则及连续计数保存于 SQLite `alert_rules`，重启保留。事件 `alert_events` 保存状态、等级、触发/最后采样/恢复/结束时间、确认人、终止原因和触发时规则及服务版本快照。规则版本防止并发覆盖；保存重试遇到 409 应刷新配置，不覆盖他人修改。

采样完成、计数变更、事件触发/恢复和审计共用一个事务；任一写入失败全部回滚。重复完成和早于已处理时间的样本不参与二次评估。配置及事件操作也具备事务审计。当前仍为单实例，事件及审计尚无自动清理策略；后续部署前须完成容量、备份、保留与清理验收。

## 接口与权限

| 接口 | 权限 / 限制 |
| --- | --- |
| `GET /api/v1/services/:id/alerts?page=1` | 授权环境内所有角色；每页 20，页码 1～100000；返回规则、事件、总数、采样状态与查询时间 |
| `PUT /api/v1/services/:id/alert-rule` | 管理员；failureCount、recoveryCount、severity、enabled、version（首次 0） |
| `POST /api/v1/alerts/:id/acknowledge` | 运维人员/管理员；仅触发态，重复确认幂等 |
| `POST /api/v1/alerts/:id/close` | 运维人员/管理员；仅已恢复，重复关闭幂等 |

沿用平台会话、上游身份核验、同源写请求校验和限流。未登录 401，无动作权限 403，不存在或跨环境对象 404，输入无效 400，并发或状态冲突 409。读取无权限资源不会返回事件细节。

## 界面与验证范围

服务“查看告警”复用共享 Dialog。管理员可编辑规则，保存前明确提示重置计数及终止活动事件；草稿有 Escape/关闭/页面离开保护，409 保留输入。有草稿时禁用刷新、翻页和事件操作。事件每页 20 条，显示分页和总数；这是手动刷新的查询快照，关闭后返回来源按钮焦点。

已验证规则计数、触发去重、确认/恢复/关闭、中断和窗口间隔、撤销、重启、审计失败回滚、角色及环境隔离。UI 使用隔离合成事件真实调用本平台 API，409/503 场景通过浏览器注入；没有真实 MedicalCareWeb 生产告警。

外部通知、发送重试、通知状态、时间持续型规则、业务/资源阈值及维护静默尚未实现。F06a/F06b 完成不代表完整 F06 或生产验收完成。

## 环境告警中心（F06b，2026-09-08）

`GET /api/v1/alerts?environmentId=local&state=active&page=1` 返回授权环境内的事件，state 允许 active、all、firing、acknowledged、recovered、closed、terminated，默认 active；页码 1～100000，每页 20。参数错误返回 400，未登录 401，环境未授权 403。返回当前服务名称及负责人，不返回其他环境数据。按触发时间倒序、事件 ID 倒序稳定排序；页码超过结果范围时返回最后有效页，空结果回到第一页。

汇总和列表在同一 SQLite 读取事务内计算。counts 包含该环境全部状态数量，active 为 firing + acknowledged，criticalActive 仅计严重活动事件；这些汇总不随筛选或页码变化。事件等级是触发时快照，不能替代当前探测状态。

概览提供“查看当前环境告警”链接；中心可定位同页服务，或打开现有服务告警面板处理。服务面板展示该服务的事件列表，不自动定位任意历史事件页。中心筛选和页码写入 URL 的 alertState/alertPage，刷新可恢复；切换环境重置为活动告警第一页。页面可见时每 30 秒刷新，任何服务弹窗开启时暂停，关闭后重读处理结果。

首次/筛选加载不显示旧筛选结果；普通刷新期间保留带查询时间的快照和焦点，失败后清除旧事件并提供重试。权限失效返回登录。若处理后原行不再符合筛选，关闭面板后将焦点回退到告警中心。中心复用原服务面板的权限、确认和关闭动作，不新增批量操作或通知发送。
